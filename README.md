# Projeto Trilha - Backend & Base de Dados

Bem-vindos ao repositório oficial do backend do sistema Trilha. Este ambiente foi estruturado utilizando **Django** conectado a uma base de dados **Supabase (PostgreSQL)**.

## 🚀 Como começar a trabalhar neste projeto (Para a Equipa)

Siga estritamente estes passos no seu terminal (VS Code) assim que descarregar o projeto:

1. **Abra a pasta correta no VS Code:**
   Certifique-se de que abriu a pasta `backend` como a raiz do seu editor.

2. **Instale as dependências automáticas:**
   O projeto já possui todas as bibliotecas mapeadas. Instale-as executando:
